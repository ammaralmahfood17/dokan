## 4. ما لم يُتحقق (صريح)

1. **`npm run test:e2e` الكامل** يتوقف عند `createTestUser failed: {}` — نفس سبب P0 الذي تخطّاه المالك (أعمدة `auth.users` الافتراضية NULL). لا علاقة له بتغييرات Phase 3.
2. **super-admin** لم يُختبر (لا بيانات دخول).
3. **تجربة اللمس على جهاز حقيقي**: القياس عبر `hasTouch` في Chromium، لا على تابلت فعلي.
4. **التسجيل مغلق** (`SIGNUP_ENABLED=false`)، فالمسار قيس ابتداءً من وجود حساب — لا من صفحة التسجيل.
