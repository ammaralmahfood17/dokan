## معايير الإنجاز لكل موجة

- **Wave 1:** كل بند ≤ يوم، مع اختبار وحدة/Playwright، و`lint`+`tsc`+`vitest`+`a11y` خضراء، ولقطة قبل/بعد.

- **Wave 3:** مستند تصميم تقني فقط (نموذج البيانات، أثر RLS، خطة إطلاق، مخاطر) — بلا كود.
